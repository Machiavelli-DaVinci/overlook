# Overlook logos for external platforms

Generated by `python3 branding/source/build_logos.py` (fontTools + rsvg-convert). Edit the script, not the files.

| File | Use |
|---|---|
| `overlook-logo-120.png` | Google OAuth consent screen / Google Auth Platform branding (120×120 PNG, well under 1 MB) |
| `overlook-logo-256.png`, `-512.png`, `-1024.png` | App listings, store pages, website; rounded midnight tile with transparent corners |
| `overlook-logo-square-*.png` | Platforms that apply their own corner mask (GitHub organization avatar, Flathub screenshots, favicons) |
| `overlook-logo-paper-512.png` | Light-surface contexts where a dark tile would be too heavy |
| `overlook-social-preview.png` | GitHub repository social preview (1280×640) and link cards |
| `*.svg` | Vector sources of the tiles and the card |

The tile is the app icon from the brand system: ivory horizon mark and amber beacon on midnight. Do not add shadows, gradients, or text to the tile; the social card is the place for the editorial line.
