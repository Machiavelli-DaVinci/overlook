# Overlook

**A clear view of what matters.** A native Linux mail client written in Rust, by [Last Refuge](https://lastrefuge.ai/).

- Product plan, brand system, and implementation notes: [`llm-docs/`](llm-docs/README.md)
- Brand assets, tokens, and design previews: [`branding/`](branding/)
- Application source: [`crates/`](crates/) (Rust workspace, GPUI user interface)

```bash
cargo run -p overlook
```

See [`llm-docs/overlook-native-app.md`](llm-docs/overlook-native-app.md) for building, testing, data locations, and keyboard shortcuts.
